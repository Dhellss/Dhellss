## 🚀 Apps &amp; Tools

| 🧭 **[LifeOS](https://github.com/Dhellss/LifeOS)** | Tasks, projects, habits, study sessions and journals in one private workspace. Every number on screen is an aggregate query against your own rows — no placeholder data · `Next.js 15` `TypeScript` `Prisma` `PostgreSQL` |
